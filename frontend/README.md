# مغازة البركة — نظام إدارة المحل

تطبيق واجهة أمامية فقط (Frontend only) لإدارة محل بقالة/عطّار تونسي، مبني بـ React + Vite + Chakra UI، باللغة العربية واتجاه RTL بالكامل. جميع البيانات وهمية (mock) ومخزّنة في حالة React (React state)، بدون أي خادم أو قاعدة بيانات.

## التشغيل

```bash
npm install
npm run dev
```

## بيانات الدخول التجريبية

- اسم المستخدم: `admin`
- كلمة المرور: `123456`

## الأقسام

الرئيسية، المبيعات (نقطة بيع كاملة POS)، المخزون، المشتريات والموردون، الحرفاء، الحسابات (الصندوق، المداخيل، المصاريف، الديون)، التقارير، الإعدادات.

## البنية التقنية

React 19، Vite، JavaScript (بدون TypeScript)، Chakra UI 2، React Router 7، Lucide React، Recharts للرسوم البيانية.
